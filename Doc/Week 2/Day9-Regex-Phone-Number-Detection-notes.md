Today, I am writing code to detect phone numbers using regex.

My goal is to create code capable of detecting phone number entities. I have updated the existing codebase by adding a `/detect` route to `redact.py` and defining detection schemas for the `DetectionEntity()` and `DetectionResponse()` functions in `request_response.py`. Additionally, I created `detection_service.py` to handle the business logic for both the current regex-based detection method and the upcoming NLP-based detection.

I am using the regex patterns `\b(?:\+62|62|0)` and `(?:[\s-]?\d){8,13}\b`. The concept involves using `\b` as a boundary to ensure the text match is treated as a complete unit (a whole word) rather than just a partial match. Regarding `(?:\+62|62|0)`, the use of the `|` operator (meaning "or") allows the pattern to match `+62`, `62`, or `0`, thereby accommodating phone number formats from various regions.

Next is the `(?:[\s-]?\d){8,13}` section. The `(?: )` construct groups the pattern into a single unit without storing it as a capturing group. Inside, `[\s-]` selects one of the specified characters: `\s` for a space or `-` (hyphen), which may appear as a separator in certain phone number formats. This part is followed by `?\d`, where `?` makes the preceding element optional and `\d` represents a digit (0–9). Finally, `{8,13}` is a quantifier specifying a repetition range of 8 to 13 times; thus, the `(?:[\s-]?\d)` pattern repeats 8 to 13 times to match that sequence of spaces/hyphens and digits.
