Today, I am going to learn about regex.

A regular expression, or regex, is a pattern-based language used to search for, match, or replace text based on specific patterns. Regex becomes powerful when it provides patterns for these operations, working by defining specific patterns for particular conditions. For instance, if a regex includes a dot (.)—such as `a.c`—then combinations like `abc`, `a-c`, or `azc` would all match that pattern; the only exception is the sequence `ac` on its own, which would not match. So, what characters are used in regex patterns? There are several: the dot (.) represents a single character; `\d` represents a digit (0-9) and can be combined (e.g., `\d\d` for two digits); the plus sign (+) indicates "one or more" occurrences; the asterisk (\*) indicates "zero or more" occurrences; the question mark (?) denotes an optional element (present or absent); square brackets [] define a character class (e.g., `[a-z]` accepts only lowercase letters from a to z); and parentheses () are used for grouping (e.g., `(abc)` ensures the pattern matches the specific sequence `abc`). When is regex suitable to use? It is ideal when the target words or sentences follow a pattern that can be leveraged for filtering, searching, and matching. Regex patterns are fast at recognition and lightweight, as they do not require AI models; they are well-suited for handling data that shares similar structural patterns. When is regex unsuitable? Conceptually, regex patterns recognize patterns without understanding the underlying concepts; for example, verifying a name is better handled by an AI model than by regex, as regex simply enforces specific conditions without grasping the actual concept of a name. Python includes a built-in library called `re` for working with regular expressions, making them highly useful for data validation, searching, and matching. To use this library, simply use `import re` to enable regular expression patterns in Python. Here are the primary functions: `re.compile()` is used to compile a regex pattern; `re.search()` searches for the first match in the text; `re.findall()` finds all matches in the text; and finally, `re.match()` looks for a match only at the beginning of the text.
